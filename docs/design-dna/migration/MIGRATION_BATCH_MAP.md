# Design DNA — Migration Batch Map

Status: MASTER-LOCKED OPERATIONAL PACKAGING

Migration batch membership is operational packaging, not ontology. Every unit retains its canonical ID, lineage, ownership, provenance and EQ3 contract.

`CALIBRATION BATCH != MIGRATION BATCH`

`271 CALIBRATED UNITS != 271 USER-FACING THEME BUTTONS`

## Four migration layers

1. Foundation / Engines — resolver, Material, Environment, shared primitives.
2. Reference Theme Families — Cultural, Country-Web, Personal Media, Music/Temporal and eligible named materials.
3. Composition / Torture Fixtures — resolver regression/integration contracts.
4. Asset enrichment — only after structural/asset-off projection is healthy.

## Recommended operational sequence

### M0 — Runtime machinery

No DNA-count batch. Establish manifest loader, resolver, semantic zones, ownership, dominance caps, contradiction budgets, degradation states, accessibility veto, Reading Sanctuary, provenance, theme selection, asset states and A→B→A state preservation.

### M1 — Engine proving

Material M1–M15 + Environment E1–E14 = 29 engines.

### M2 — Structural identity proving slice

Country-Web 5 + selected adversarial Cultural Tier-S representatives + only the primitives required for the slice. Purpose: prove whole-application morphology can change without wallpaper/stereotype behavior and without state mutation.

### M3 — Cultural Tier S

16 active Tier-S references.

### M4 — Complete primitive families

P01–P25 + MK01–MK25 + TP01–TP18 = 68 primitives.

### M5 — Izzul Personal Media

M5B Manga 11

### M6 — Miko Personal Media

23 references. Sub-batch only from authoritative medium metadata. Do not invent Miko Anime symmetry.

### M7 — Izzul Music / Temporal

Track T-I 16 references, using TP machinery. Music DNA contributes temporal/narrative/rhythm behavior; it is not a command to play protected recordings in the UI.

### M8 — Cultural Tier A

29 active references, internally sub-batched as needed.

### M9 — Cultural Tier B

10 active references.

### M10 — Track M_R

25 named/reconstructed material references. Preserve `M1–M15 != TRACK_M_R != HISTORICAL TRACK M`.

### M11 — Full fixture torture

14 additive fixtures. Test resolver composition, responsive behavior, accessibility, Reading Sanctuary, asset-off, collision/fallback, explainability and A→B→A state continuity.

### M12 — Asset enrichment

Select and prove production-eligible assets only after structural identity works. Asset-on may be rich; asset-off remains the resilience floor.

## Per-batch governance

`SELECT → IMPLEMENT → TEST → GOVERNOR REVIEW → PATCH FAILED UNITS → ACCEPT → LOCK → NEXT`

Already-passing batches are not reset because a later batch fails. Codex/implementer translates accepted contracts into the host; it does not invent missing DNA.

## Boundary

This map does not authorize migration. Migration Gate Review is a separate explicit decision. EQ4 begins only with real authorized host implementation/runtime/browser evidence.
