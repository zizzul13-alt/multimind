Together with the five Country-Web references, the slice covers order/asymmetry, restrained/expressive structure, controlled density, service convergence, language continuity, motion/calm, navigation/traversal, Reading Sanctuary, mobile recomposition, and reference/engine ownership tension.

- role/grid → ordered flow,
- task components → reflowed state grammar,
- controlled density → serialized local groups,
- service convergence → serialized bounded service clusters,
