- reconciled current truth;
- modular navigation;
- current governance;
- current denominators/status;

- migration-readable structure.

Layer B — raw historical archive

- every recoverable old Markdown artifact copied verbatim;
- original filename preserved where possible;
- collisions/duplicate names receive stable disambiguation without editing file content;
- superseded files remain intact;
- failed research routes remain intact;
- branch briefs remain intact;
- old locks/checkpoints remain intact;
- no cleanup by rewriting source text.

Canonicalization never substitutes for raw preservation.

## Exactness rule

A source may be marked `RAW_ARCHIVED_VERIFIED` only when the full source content was retrievable and written without intentional omission, summarization, reconciliation or truncation.

Search snippets, truncated previews and semantic summaries are NOT sufficient for a verbatim archive claim.

If the available retrieval interface truncates a source, classify it:

`RAW_ARCHIVE_PENDING_FULL_SOURCE_ACCESS`

Never reconstruct missing words from memory or summaries.

## Duplicate rule

Same filename != proven duplicate.

True duplicate classification requires sufficient content identity evidence. Until proven, preserve both source identities. If two different files share a filename, disambiguate the GitHub path while retaining the original filename in the source manifest.
