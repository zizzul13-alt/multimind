- `RAW_ARCHIVED_AWAITING_VERIFICATION` — raw file exists in GitHub, but source↔GitHub exact comparison has not yet been recorded.
- `RAW_ARCHIVED_VERIFIED` — full source was retrieved and GitHub fetch-back comparison has been recorded as matching for the content available from the source tool.

- `SUPERSEDED_HISTORICAL` — historical source preserved because later accepted state supersedes it.
- `SOURCE_NOT_YET_DISCOVERED` — known family/artifact is expected from lineage but exact source has not yet been found.
