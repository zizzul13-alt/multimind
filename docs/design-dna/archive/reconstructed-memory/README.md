# Design-DNA Memory Reconstruction Surrogates

STATUS: ACTIVE ARCHIVAL FALLBACK LAYER
DATE: 2026-09-04

This directory exists for historical Design-DNA Markdown artifacts whose exact full source is known to have existed but cannot currently be retrieved in full.

## Hard distinction

`RAW VERBATIM SOURCE != MEMORY RECONSTRUCTION`

Files in this directory are NEVER evidence that the original byte/text content has been recovered.

Every surrogate is derived only from one or more of:
- surviving File Library fragments/snippets;
- later durable Design-DNA artifacts that explicitly cite or inherit the source;
- current canonical reconciliation records;
- project memory retained from the historical research sequence.

They preserve the recoverable decisions, counters, relationships, chronology, and governance meaning without fabricating missing original prose.

## Status

Use:

`MEMORY_RECONSTRUCTED_SURROGATE`

and, where applicable:

`RAW_EXACT_TEXT_UNAVAILABLE`

`SOURCE_ID_KNOWN_BUT_TRUNCATED`

`SOURCE_ID_NOT_RECOVERED`

A memory surrogate does NOT permit the raw archive to be called verbatim-complete for that original source. It does permit the source-disposition census to close truthfully rather than leaving an unbounded TODO.

## Reopen rule

If the exact full source is later recovered:
1. preserve this surrogate as historical recovery evidence;
2. mirror the exact source into `../raw/`;
3. mark the surrogate `SUPERSEDED_BY_RAW_RECOVERY` in the manifest;
4. never replace exact source text with the reconstruction.
