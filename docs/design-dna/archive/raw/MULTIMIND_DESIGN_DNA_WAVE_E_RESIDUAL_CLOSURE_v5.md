# 4. TYRANT — INSPECTABLE EVIDENCE ACQUIRED

## 4.1 Official separated samples

Legal direct observations were made on official Naver Webtoon episode pages at widely separated locations:

- **Episode 20** — early corpus position.
- **Episode 50** — separated later sample.
- **Episode 80** — separated later sample.
- **Episode 103** — later strategic-context sample.
- **Episode 150** — substantially later sample.

The observations below describe only formal behavior. No panel image is reproduced and no long copyrighted text is transcribed.

## 4.2 Recurring observations

### Episode 20
Multiple image segments place dialogue, action, or small focal elements between **large vertical white intervals**. In several locations, a small textual or visual beat is isolated before the next scene field. This demonstrates that whitespace is not merely a page margin; it participates in sequential segmentation.

### Episode 50
The same pattern recurs: dialogue or scene fragments are separated by unusually generous vertical white intervals, producing discrete reading beats rather than a continuously packed strip.

### Episode 80
Separated speech/action moments again use large white fields and small isolated detail regions. The recurrence at a distant episode rules out an episode-20-only layout accident.

### Episode 103
This is the strongest title-specific closure point. Besides the recurring white-interval segmentation, one observed sequence presents **stage/deployment context in rectangular narration/information boxes isolated on a large white field**, between ordinary scene material. This establishes a direct formal bridge between:
- narrative/action field;
- strategic/system context;
- scroll-space punctuation.

It is therefore no longer necessary to infer “tactical grammar” merely from the tower-defense premise.

### Episode 150
Large vertical interval segmentation recurs yet again around dialogue and scene fragments, demonstrating durability across a long span of the serialization.

## 4.3 Recurrence conclusion

The recurring behavior is **not** “tower defense UI”. It is narrower:

> **STRATEGIC_CONTEXT_INTERVALIZATION** — repeated use of scroll-space / negative-space punctuation to separate immediate narrative/action fields from context, decision, or strategic information; strategic context may appear as isolated structured text/information fields rather than being visually fused into the scene.

This mechanism is supported by:
1. recurring interval segmentation across separated official episodes; and
2. at least one directly observed explicit strategic/deployment-context block in a later official episode.

The premise establishes what the strategic information means; the direct panels establish how it is formally staged. These two evidence layers are kept separate.

## 4.4 Mechanism reformulation

**Before v5:** defense topology + human consequence; tactical-context candidates not closed.

**After v5:** **STRATEGIC_CONTEXT_INTERVALIZATION**.

Nearest existing primitive lineage:

- **P02 NEGATIVE_SPACE_PACING**
- **P13 EDITORIAL_SEGMENT_PUNCTUATION**
- **P05 STATE_OVERLAY** where structured system/status information is present
- optional relationship to **P17 SYSTEM_WORLD_DUAL_LAYER**, but no new primitive is required.

No primitive invention is needed because the reference contribution is a **title-specific combination and ownership contract**, not a new engine behavior.

## 4.6 EQ3 projection contract

**Archetype affinity**
- primary: Command Center
- secondary: Agent Canvas
- conditional: Chat-first where strategic context must be interleaved with narrative/work history

**U1–U9 ownership**
- U1 SHELL: neutral; reference does not own global shell.
- U2 PRIMARY_CONTEXT: eligible for explicit strategic/context heading.
- U3 PRIMARY_WORK_SURFACE: canonical work remains primary.
- U4 WORK_ITEM: work-item truth never stylized into fictional game state.
- U5 PRIMARY_ACTION: remains conventional and immediate.
- U6 SYSTEM_STATE: canonical state labels remain authoritative.
- U7 READING_SANCTUARY: excessive interval spacing is demoted; grouping survives.
- U8 AUXILIARY_CONTEXT: primary eligible zone for strategic/context blocks.
- U9 PROVENANCE_DISCLOSURE: source/reference wording.

**Dominance**
The mechanism may dominate only when the user is moving between immediate work/action and strategic/planning context. It may not permanently transform the product into a game dashboard.

**Desktop**
Context blocks may sit adjacent to the work surface or appear as clearly separated vertical sections.

**390×844 / 320 CSS px**
Physical whitespace is compressed, but semantic interval boundaries remain through spacing + headings/dividers/container grouping. No desktop stacking, hidden status, or scroll trap.

**Reading Sanctuary**
Reduce large gaps and decorative framing to ordinary readable section spacing while retaining context/action separation.

**Reduced motion / low power**
No motion required.

**Asset-off**
Full survival. Neutral text blocks, labeled status/context groups, ordinary separators, and explicit relationships preserve the mechanism.

**Deterministic fallback**
If spacing budget is unavailable, replace whitespace dominance with labelled section boundaries. Meaning remains identical.

**State continuity**
A→B→A presentation switching may not mutate task status, resource values, object identity, scroll target, or action history.

**Forbidden projection**
- tower-defense HUD skin;
- RPG counters without real product semantics;
- fantasy ornament;
- fake resource scarcity;
- copied maps/panels/icons;
- whitespace that merely increases scroll distance;
- tactical animation required for comprehension.

## 4.7 Fixtures

**Positive fixture**

A Command Center displays an active work item normally. When planning or contextual dependencies become relevant, a separated context block is introduced after a clear interval and carries labelled deployment/dependency/resource information. Returning to the work item preserves its state, focus, and position. On narrow mobile the physical gap shrinks but the context boundary remains explicit.

**Reference-specific negative fixture**

A globally accessible and semantically correct dashboard still **FAILS this reference** if it simply adds RPG cards, counters, or a tactical-looking map while immediate work and strategic context remain visually undifferentiated. It also fails if large blank scroll gaps appear without an actual context/decision boundary. Accessibility may pass while the Tyrant mechanism specifically fails.
