# MultiMind Design DNA — Canonical Constitution

Status: CURRENT CONSOLIDATED GOVERNANCE

## Source precedence

1. Current authoritative repository/files for implementation facts.
2. Latest explicit user/HQ decision.
3. Latest accepted MASTER LOCK/checkpoint.
4. Latest accepted research/calibration artifact.
5. Older artifacts for historical reconciliation and cumulative research inheritance.

Latest explicit user decision overrides older state. Historical artifacts are never silently erased merely because a later lock supersedes one of their claims.

## Core model

Design DNA is a mechanism-composition system, not a theme-skin catalog.

Priority:

`Safety/Accessibility > Data/Feature Semantics > Archetype > Reading Sanctuary > Web behavior > Cultural identity > Material > Environment`

Composition:

`Application State → Semantic UI Model → Archetype Projection → Cultural DNA × Web DNA → Material → Environment → Adaptation / Accessibility / Performance → Final Representation`

Hard rules:

- resolve before render;
- no style averaging;
- semantic ownership first;
- vetoes outrank aesthetics;
- dominance is scoped by axis × semantic zone × viewport/state;
- productive tension may survive when bounded;
- fallback is part of identity;
- provenance survives composition;
- runtime theme changes presentation only; application state survives;
- direct artwork/character/panel/recording dependency is license-gated;
- identity must survive asset removal.

## Reading Sanctuary

Long-form prose, evidence, code/logs, research content and other reading-heavy surfaces receive strong aesthetic demotion. Identity is preserved through structure rather than ornament that harms reading.

## Accessibility

Accessibility is a super-veto. Target WCAG 2.2 AA where applicable. Aesthetic ownership cannot override semantic truth, keyboard/focus requirements, readable contrast, motion safety, language metadata, or equivalent-access requirements.

## Full-Pass law

Every eligible target in an active governed wave must eventually pass its required maturity gate. HOLD is temporary. `COMPLETE WITH HOLDS`, `FINAL HOLD`, weakened standards, invented evidence, genericized identity, silent routing, popularity-as-evidence, or direct-IP dependency are forbidden terminal shortcuts.

Failure and dead routes are cumulative research knowledge and must be retained.

## Asset law

`ASSET-OFF SURVIVAL IS A RESILIENCE REQUIREMENT, NOT AN ASSET-MINIMIZATION REQUIREMENT.`

`ASSET-OFF CAPABLE != ASSET-AVOIDANT`

`MECHANISM-FIRST != ASSET-FORBIDDEN`

FULL fidelity may be visually rich when assets are production-eligible. Three relevant runtime states must remain safe: asset available/loading, partial failure, and asset-off. Public-domain/CC0/original/commissioned/compatible assets may be candidates with provenance; personal-use-only, reference-only, unknown-rights, or protected direct-IP source media may not be silently shipped on a public production web app.
